# Portfolio Page Wording

## Project Card Title

Technician Command Center

## Short Description

A Flask and SQLite diagnostic toolkit for IT technicians that captures endpoint, network, service, printer, and performance snapshots, compares before/after troubleshooting states, and exports support-ready reports.

## Longer Description

Technician Command Center is a hands-on IT support project designed to simulate a real technician workflow. It allows a technician to create diagnostic snapshots, review issue-focused findings, compare before/after troubleshooting states, and export reports for documentation or escalation. The app includes a safe public demo mode with sample data and a local mode that collects real machine diagnostics when run on a technician workstation.

## Skills Demonstrated

- Python and Flask development
- SQLite database design
- IT troubleshooting workflows
- Endpoint diagnostics
- Network troubleshooting
- Printer and service diagnostics
- Technical reporting and documentation
- Before/after root-cause comparison
- Portfolio-safe demo design

## Suggested Live Demo Script

1. Open the dashboard and explain the purpose.
2. Seed the portfolio demo data.
3. Open a DNS issue snapshot.
4. Show the issue-focused view and findings.
5. Compare DNS issue before/after with a healthy endpoint.
6. Open the Reports page.
7. Download the ZIP support bundle.
8. Explain that Local Mode collects real diagnostic data when run on a technician machine.
